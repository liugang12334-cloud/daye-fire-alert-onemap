本版修订范围（18 号 · 方案 A / P0）

已落实的 P0 修正（4 项）
  • ① 页面定位声明为业务原型（示意数据，非真实数据大屏）；
  • ② 三套分级写全限定词，消除「响应等级」与「火险等级」混用；
  • ③ 清除已下线的蓝色工单档残留；
  • ④ 告警研判确认后一次完成工单生成与派发，工单起点为「待签收」。
本轮增量（首页应急资源 / 感知设备详情）
  • 首页地图上的应急资源点位（7 处）与感知设备点位（4 处）支持点击查看只读档案；
  • 地图头「应急资源 / 感知设备在线」计数可点击查看同类点位清单，清单行可继续下钻单项详情；
  • 详情复用右侧既有弹窗，档案取自现有示意台账，不新增数据源 / 业务模块，不改写既有交互。
保留的既有交互（行为不变）
  • 研判结论、确认属实生成并派发 / 签收 / 处置 / 核查 / 归档、物资调拨、AI 辅助建议；
  • 指标着色与图层切换、点位与表格下钻、详情抽屉与在首图定位等。
  • 本版不扩展数据接入、业务实现与额外重构。

页面结构

  • 态势总览：首屏主地图承载监控、研判、派发、处置、核查、归档全流程，右侧弹窗内闭环。
  • 应急资源 / 运行监测：均为「中间地图 + 两侧数据指标」的只读页，点击乡镇分区或点位查看详情，不承担工单流转。
  • 运行监测页支持三种指标着色切换（48h 告警数 / 巡护签到率 / 设备在线率）与五类图层开关。
  • 原「告警研判」「工单处理」「应急处置」「质效评估」独立内容入口已取消。

业务规则（会议 376469705）

  • 两套调度：指挥中心调度（常规工单）与基层一键调度（失控 / 专业处置需求，按等级触发）。
  • 黄色工单：误报确认权下放乡镇值班室，指挥中心不介入处置。
  • 预警研判阶段的「判定误报 · 归档」由当前角色行使；黄色工单生成后的误报确认权仍归乡镇值班室。
  • 角色权限：指挥长与乡镇值班室按工单状态分工；AI 采用「辅助 + 人工确认」，可回退纯人工。
  • 弹窗固定在地图右侧，可收窄、可收回；告警点联动展示周边救援物资。

数据口径

  • 三套分级必须写全限定词且互不混用：火险·蓝/黄/橙/红（事前预防）、工单·黄/橙/红（事中未成灾）、响应·Ⅳ/Ⅲ/Ⅱ/Ⅰ级（事中成灾）；原「Ⅳ 级 高」属响应等级与火险等级混用，本版已修正。
  • 近 30 日统计；同一坐标 500m、10 分钟内重复识别合并为 1 条告警。

统计与待确认事项

  • 乡镇分区为值守责任区示意，非民政行政区划边界；地图为重点点位示意，与设备台账 28 台不完全一一对应。
